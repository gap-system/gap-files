files.gap-system.org

Archives of the GAP computer algebra system and of its packages.

This server exists for two reasons. It keeps a copy of everything we distribute that is independent of GitHub, so that a serious outage there does not leave GAP undownloadable. And it is the archive of record for older package releases: package authors routinely remove old versions from their own sites, and a copy here may well be the only one left. Nothing is ever deleted from this server.

For current downloads, please prefer the canonical locations: GAP releases from the GAP repository or the installation instructions, and packages from the ArchiveURL given in their PackageInfo.g. Those are served by a CDN and will normally be faster. Use this server when you need an old version, or when the canonical location is unavailable.

What is here

There are no directory listings: this server was repeatedly scraped in its entirety, costing gigabytes of traffic a day, so browsing had to be turned off. The layout below is therefore documented rather than listed, so that you can construct the URL you need.

/pkg/
Every package archive that has been part of the package distribution, current and historical. Archives live in a directory per package, for example /pkg/browse/Browse-1.8.23.tar.gz.
The archive file name and its checksum for any current package are recorded in the PackageDistro repository, in packages/<package>/meta.json.
/gap-4.16/, /gap-4.15/, … /gap-4.9/
One directory per GAP 4 release series from 4.9 onwards, holding every release in that series. From 4.12 on the layout is /gap-<major>.<minor>/<format>/gap-<version><suffix>, where format is tar.gz, zip or exe, for example /gap-4.16/tar.gz/gap-4.16.0.tar.gz. A -core variant without the packages exists alongside the full archive, and every archive has a matching .sha256 file. Series 4.9 to 4.11 predate those conventions and additionally offer tar.bz2, zip and win.zip.
/gap44/ … /gap48/
GAP 4.4 to 4.8, in the layout used at the time, with a directory per format (tar.gz, tar.bz2, zip, win.zip, and zoo for 4.4). Each of those holds a packages/ directory with the package versions that shipped alongside those releases, for example /gap48/tar.gz/packages/.
/gap-3.4.4/
GAP 3.4.4, the last release of GAP 3, together with its bugfixes and deposited files.

Further locations still resolve, so that links published long ago keep working. They are kept deliberately, but anything not described above should not be used for new work.

How it is kept up to date

Package archives and GAP releases are mirrored automatically, within about fifteen minutes and an hour of publication respectively. Every download is verified against the checksum published with it before being put in place. The scripts that do this, and the documentation of the server itself, are in the gap-files repository.

Please report anything missing or broken to the issue tracker or to support@gap-system.org.
